Finders Keepers is a Java 25 and JavaFX lost-and-found desktop application for primary schools. It gives Students and Desk Officers separate, focused workspaces for moving an item from its first report to a safe return.

![Finders Keepers login page](images/readme/login-page.png)

## One complete return workflow

1. A **Student** reports a lost or found item and searches their own report history.
2. A **Desk Officer** reviews reports and links a likely lost-and-found pair.
3. The Student submits ownership evidence as a Claim.
4. The Desk Officer approves or rejects the Claim after reviewing the evidence.
5. For an approved Claim, the Desk Officer creates a collection slot and the Student books it.
6. The Desk Officer records custody, confirms collection, returns the item, and closes the case with an audit history.

## Reliability and privacy

The project uses automated tests, Checkstyle, warning-free Java compilation, Javadoc validation, JaCoCo reports, multi-platform CI, packaged-application smoke tests, strict local persistence, and privacy-narrow role projections. Public examples and screenshots use synthetic data only.
